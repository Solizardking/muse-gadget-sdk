Solana Gadget Kit

The premiere official open-source home of all Solana gadgets and hardware.

Host programs you can run on a computer, the 240×240 round review surface, the ESP32 and Linux device SDKs, the Android and iPhone test apps, Solana OS 0.4.4 for the BP26 badge, the badge flash script, the browser flasher, the community device skills, and Pocket Wallet in full. The kit documents live in the root README. Source: github.com/themusebook/solana-gadget-kit.

240×240 review surface

The on-device hardware wallet signs only after a physical confirm. Pocket Wallet stays the phone-approval path and cannot sign or submit. Robotics motion is applied only for a matching Solana confirmation.

HOME Solana gadget
  • Home is idle. No command is bound.
  • Review shows the exact payload before a signature exists.
  • Expired and cancelled refuse the robotics actuator.

Gadgets and hardware in this tree

These programs do not flash a board, open a network connection, or read a provider key. Build them with make -C solana test examples.

Hardware wallet

hardware_wallet refuses to export the secret, shows the review line, and signs only after a physical confirm. The public demonstration seed is not a funded key.

LCD status

lcd_status drives home, review summary, expired, and cancelled on the 240×240 surface.

Robotics gate

robotics_gate applies servo:15 only for a matching confirmation. Mismatch, expiry, cancel, and a missing confirmation are refused.

Solana OS check

solana_os_check checks the Solana OS 0.4.4 bundle against SHA256SUMS. Flash notes are in solana/docs/solana-os.md.

Portfolio preview

portfolio_preview renders a fixed SOL/USDC quote. It does not request a live quote or submit a trade.

Solana BP26 badge

Prebuilt Solana OS 0.4.4 for the ESP32-C5 badge, in firmware/solana-os/0.4.4. Flash it with scripts/flash-solana-os.sh after the checksum check. Notes: docs/solana-os.md.

SDKs, phone apps, and badge firmware

The device SDKs and the prebuilt Solana OS images. Flashing custom firmware can brick a board. The phone apps are samples. They do not hold a wallet key.

Scripts

scripts/flash-solana-os.sh flashes Solana OS 0.4.4 onto a Solana BP26 badge (ESP32-C5, CH340) with esptool 5. It checks SHA256SUMS first, writes at 460800 baud, and can erase settings or internal storage when you pass the matching flag.

Update

scripts/flash-solana-os.sh PORT writes the bundle and keeps Wi-Fi, calibration, theme, and server address.

Erase settings

--erase-settings also clears 0x9000 for 0x6000 bytes. The badge says hello again with a new secret.

Erase all

--erase-all also clears internal storage at 0x11000 and 0x820000, like a new badge.

Web flasher

web-flasher/ is the GitHub Pages page that installs Muse gadget firmware from Chrome or Edge over Web Serial, using ESP Web Tools 10.4.0. CI packages the boards in boards.json and deploys on pushes to main. The page builds ship without an SDK token. After install, sdk-token.js sends the maker’s token over serial once. The Solana BP26 entry points back at scripts/flash-solana-os.sh when you need 460800 baud or an erase.

PathWhat is included
index.html The installer page. It pins esp-web-tools@10.4.0.
boards.json Board picker: id, name, optional USB ids, pacing, and the note shown for that board.
flasher-hooks.js Limits the port picker to the board’s USB devices and refuses a flash the partition table cannot fit.
paced-serial.js Small Web Serial writes with a pause, for USB-UART bridges that drop bytes. Used by the SenseCAP Watcher.
sdk-token.js Checks an mgst_ token and sends it as >sdk_token=…. The gadget stores it in NVS.
make_manifest.py Copies one board’s flash images and writes an ESP Web Tools manifest. Images stay at their own offsets, so an update does not wipe NVS.
README.md How the page is built, how a token is set, and how to add a board.

Pocket Wallet, included

Phone approval for the round-screen gadget. A physical press on the ESP32 advances to phone review. That path cannot sign or submit. Signing stays in the installed Solana wallet. The running app is wallet.musebook.trade, with device setup at /pair.
